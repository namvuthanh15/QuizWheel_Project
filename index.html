          Đăng dữ liệu lên web

          Ghi thẳng file dữ liệu vào kho GitHub của bạn, không cần xuất/nhập file.

          Chỉ dùng chữ, số, . _ - và /; phải là file .js; không bắt đầu bằng / và không chứa ..

          Mã chỉ được giữ trong phiên này (đóng tab là mất). Nên dùng mã “fine-grained” chỉ cấp cho đúng 1 repo, quyền Contents (đọc/ghi), có thời hạn ngắn.

          Cách tạo mã (token)
          1. GitHub > ảnh đại diện > Settings > Developer settings > Personal access tokens > Fine-grained tokens > Generate new token.
          2. Resource owner: chọn tài khoản của bạn. Expiration: đặt ngắn (ví dụ 30 ngày).
          3. Repository access: chọn Only select repositories rồi chọn đúng repo QuizWheel.
          4. Permissions > Repository permissions > Contents: Read and write.
          5. Bấm Generate token, sao chép mã (chỉ hiện một lần) rồi dán vào ô phía trên.

          Không gửi mã cho ai, không dán vào chat hay vào file trong repo. Tên menu của GitHub có thể thay đổi.
